## SOS OS @VERSION@: first bootable ISO

> **Pre-release.** This is the first build of SOS OS. Expect rough edges and don't install it on a
> machine whose data you can't afford to lose.

### Highlights

- Debian 13 "trixie" base with KDE Plasma 6, Linux kernel, firmware and Mesa Vulkan drivers
- SOS Dark theme: blue/purple accents, floating translucent panel, SOS launcher, Quick Stats widget,
  SOS login screen, boot splash and wallpapers
- SOS Control Center, System Monitor, Updater, Welcome and DevHub
- Firewall on by default, no listening services, signed Debian updates
- Calamares installer with optional full-disk encryption

### Download and verify

| File | Purpose |
| --- | --- |
| `sos-os-@VERSION@-amd64.iso` | Bootable hybrid ISO (USB/DVD, UEFI and BIOS) |
| `sos-os-@VERSION@-amd64.iso.sha256` | SHA-256 checksum |
| `sos-os-@VERSION@-amd64.packages` | Every package and version in the image |

```bash
sha256sum -c sos-os-@VERSION@-amd64.iso.sha256
```

### Installation

1. Write the ISO to a USB stick with Fedora Media Writer, balenaEtcher, Rufus (DD mode) or `dd`.
   **This erases the stick.**
2. Boot from it (UEFI or BIOS; Secure Boot supported via Debian's signed shim).
3. Try the live desktop (user `sos`, password `live`), then double-click **Install SOS OS**. The
   installer shows every disk change and asks for confirmation first.

Full guide: [docs/INSTALL.md](https://github.com/liambush376-max/SOS-OS/blob/main/docs/INSTALL.md)

### Known issues

- Only automated QEMU boot testing has been done for this release. Real hardware, the installer and
  persistence haven't been tested yet. See
  [docs/STATUS.md](https://github.com/liambush376-max/SOS-OS/blob/main/docs/STATUS.md).
- SOS components (apps, theme) update only with a new ISO; there's no SOS package repository yet.
- Windows use Breeze decorations; fully rounded corners and a custom Plasma SVG theme come in v0.2.0.
- Intel GPUs show clock speed rather than utilisation in System Monitor (no unprivileged counter).
